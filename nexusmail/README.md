# NexusMail

Настоящая почта в один клик (через бесплатный сервис mail.tm) + помощник регистрации Steam.

- **Почта** — кнопка «Создать почту» создаёт ящик со случайным адресом и паролем (10 символов).
  Нажмите на ящик в списке — откроются его письма. Коды подтверждения (Steam Guard, Discord и т. п.)
  находятся автоматически и копируются в буфер.
- **Steam** — логин и пароль можно вписать самому или сгенерировать. Кнопка создаёт почту и открывает
  окно регистрации Steam: почта вписана, страна — Украина. Вы отмечаете согласие и проходите капчу,
  письмо подтверждается автоматически, затем подставляются логин и пароль. По нажатию на логин в
  списке видны логин/пароль Steam и почта/пароль от почты.
- **Почта для Steam** — «Новая временная» (mail.tm, подтверждение автоматически) или «Своя» (Gmail, Outlook и т. д. —
  ссылку из письма Steam нажимаете сами, дальше окно Steam подставит логин и пароль). Некоторые временные домены Steam не принимает.
- **Настройки** (⚙) — язык RU/EN, автокопирование кода, автоподтверждение Steam, звук, уведомления.

## Запуск и сборка

```bash
npm install
npm start          # запустить программу
npm run dist       # собрать dist/NexusMail.exe (portable, без установки)
npm run dist:setup # собрать установщик dist/NexusMail-Setup.exe
```

Также `.exe` собирается автоматически в GitHub Actions (workflow «Build NexusMail.exe»), файл — в Artifacts.
Веб-версия: просто откройте `app/index.html` в браузере (без автоподстановки в Steam).
